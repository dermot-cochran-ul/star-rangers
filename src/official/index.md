<h1 class="page-title">Official Editions</h1>
<p class="page-intro">
  This page is the authority on where <em>Drithane</em> is officially published.
  Every address below is deployed by the author from the same source repository.
  <strong>If the address you are reading is not on this list, you are not reading
  an official copy</strong> — see the note on forks at the end.
</p>

<h2>The full site</h2>
<ul>
  <li><strong>sciencefiction.site</strong> — the unbranded full edition, and the canonical address.</li>
  <li><strong>dermot-r-cochran.github.io/star-rangers</strong> — the same edition on GitHub Pages, built from the public repository.</li>
</ul>

<h2>Branded editions</h2>
<p>
  Each of these is a framing of the same record — a different door into the same
  canon, never a different canon. Filtering only ever narrows what a domain
  shows; no edition can assert anything the others deny.
</p>
<ul>
  <li><strong>starquest.site</strong> and <strong>starquest.online</strong> — StarQuest.</li>
  <li><strong>fellowshipoflight.org</strong>, <strong>.site</strong>, <strong>.online</strong> and <strong>.space</strong> — Fellowship of Light.</li>
  <li><strong>church-space.site</strong> and <strong>church-space.online</strong> — Church Space.</li>
  <li><strong>undercover-pets.com</strong> — Undercover Pets.</li>
</ul>

<h2>Alias addresses</h2>
<p>
  Two older addresses serve existing editions rather than sites of their own:
  <strong>star-rangers.space</strong> (an alias of sciencefiction.site) and
  <strong>star-rangers.site</strong> (an alias of starquest.site).
</p>

<h2>About forks</h2>
<p>
  The engine behind this site is MIT-licensed and forking it is
  <a href="/star-rangers/forking/">actively welcomed</a> — an original story on
  this engine, or a clearly-labelled non-commercial fan clone, is exactly what
  the licence invites. But no fork is an official copy of <em>Drithane</em>,
  and the story content's licence does not permit republishing existing entries
  in altered form. If you find a site presenting modified versions of this
  work's canon as though they were the original, it is not mine — this list is
  the record of what is.
</p>
