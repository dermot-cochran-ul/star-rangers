<h1 class="page-title">Page not found</h1>

<p class="page-intro">
There is no page at this address. The likeliest reason is a chapter address that
has been retired: chapters get renumbered as the story's chronology settles,
which reassigns their season-and-episode URLs.
</p>

<p class="page-intro">
If you followed a citation link of the form <code>/c/&hellip;/</code>, it should
always resolve &mdash; those addresses follow their chapters through renumbering
&mdash; so a dead one is worth <a href="https://github.com/dermot-r-cochran/star-rangers/issues">reporting</a>.
</p>

<p class="page-intro">
Otherwise, the search box can find a page's current home, or start again from
<a href="/star-rangers/">the home page</a>,
<a href="/star-rangers/seasons/">the seasons</a>, or
<a href="/star-rangers/lore/">the lore archive</a>.
</p>
